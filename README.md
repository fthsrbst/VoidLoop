## 🎮 About the Project

**VoidLoop** is an anomaly-themed escape game set in an office environment. The player, as an office worker caught in a mysterious anomaly, tries to escape in an endless loop. Developed with Unity game engine, this project aims to deliver an atmospheric horror-thriller experience.

### Story
During an ordinary workday, our character encounters strange events in the office. Reality begins to warp, and they find themselves trapped in a repeating anomaly loop. The only goal: Escape and survive.

## 🎯 Gameplay

- **Endless Runner Mechanics**: The player progresses in an endless loop, constantly on the move
- **Anomaly System**: Unexpected changes and mysterious events in the office environment
- **Escape Mechanics**: Overcoming obstacles, avoiding dangers
- **Atmospheric Horror**: Tension-filled office environment and psychological elements

## ✨ Features

### Game Mechanics
- **Endless Runner System**: Continuous gameplay in an endless loop
- **Dynamic Anomaly System**: Different anomaly events in each playthrough
- **Office Environment**: Realistic and atmospheric office design
- **Difficulty Scaling**: Increasing difficulty as the game progresses

### Technical Features
- Built with Unity game engine
- C# based game mechanics
- Custom shader implementations (ShaderLab)
- Optimized performance
- Modular and extensible code structure

## 🛠️ Technologies

The project uses the following technologies:

- **Unity**: Main game engine
- **C# (66.1%)**: Primary programming language
- **ShaderLab (28.9%)**: Visual effects and shaders
- **Mathematica (2.6%)**: Mathematical calculations
- **HLSL (2.4%)**: High-Level Shader Language

## 📦 Installation

### Requirements

- Unity Hub
- Unity Editor (recommended version: version specified in project settings)
- Git

### Installation Steps

1. Clone the repository:
```bash
git clone https://github.com/fthsrbst/VoidLoop.git
```

2. Open Unity Hub and click the "Add" button

3. Select the folder of the cloned project

4. The project will appear in Unity Hub, click on it to open

5. Unity Editor will load the project and import necessary packages

## 🎯 Usage

After opening the project in Unity Editor:

1. Open the main game scene from the **Scenes** folder
2. Click the Play button to test the game
3. Move with WASD or arrow keys
4. Avoid anomalies and try to stay alive
5. Edit game object properties from the Inspector panel

### Controls
*(In development - control scheme will be updated according to the game)*
- **Movement**: WASD / Arrow Keys
- **Sprint**: Shift
- **Interact**: E
- **Pause**: ESC

## 🎮 Proje Hakkında

**VoidLoop**, ofis ortamında geçen anomali temalı bir kaçış oyunudur. Oyuncu, gizemli bir anomaliye yakalanmış bir ofis çalışanı olarak sonsuz döngüde kaçmaya çalışır. Unity oyun motoru ile geliştirilmiş bu proje, atmosferik bir korku-gerilim deneyimi sunmayı hedefler.

### Hikaye
Sıradan bir iş gününde, ofiste çalışan karakterimiz garip olaylarla karşılaşır. Gerçeklik bükülmeye başlar ve kendini tekrar eden bir anomali döngüsünde bulur. Tek hedef: Kaçmak ve hayatta kalmak.
